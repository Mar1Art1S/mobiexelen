# Хімекселен — мобільна вітрина

Модульний мобільний інтерфейс магазину вуликів із ППУ. Проєкт побудований на Laravel, Livewire та Alpine.js; каталог, пошук, контактна форма й навігація працюють без повного перезавантаження сторінки.

## Можливості

- мобільна головна сторінка та каталог категорій;
- Livewire-каталог із пошуком, фільтрами, кошиком та обраним;
- сторінка порад із відео, PDF-інструкціями та кресленнями;
- контактна форма і замовлення зворотного дзвінка;
- адаптивна нижня навігація та Alpine.js-анімації.

## Локальний запуск

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate
npm run build
php artisan serve
```

Після запуску сайт буде доступний за адресою `http://127.0.0.1:8000`.

## Перевірка

```bash
php artisan test
npm run build
vendor/bin/pint --test
```
